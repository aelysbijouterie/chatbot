# Commandes web — Gestion des retours en magasin et SAV

**Service :** WEB – MARKETING | **Mis à jour :** 20/08/2025
**Concerne :** Aélys (OCC) et Franchisés Aélys (CGE)

**Objectif :** Gérer un retour ou un SAV pour une commande web.

---

## 1. Retour en magasin

Dans le cas d'une commande en livraison ou d'un click-and-collect, le client peut se faire rembourser ou échanger son article dans n'importe quel magasin Aélys.

> ℹ️ **Le droit de remboursement n'est pas valable** dans le cas d'une **e-réservation** (produit réglé en magasin) ni pour un **produit personnalisé et/ou gravé**.

**Raisons possibles d'un retour :**
- Le produit ne lui plaît pas
- La taille ne va pas
- Le produit reçu n'est pas le bon
- L'article est défectueux

---

### 1.1 Le client souhaite se faire rembourser

**Étape 1 — Vérification du retour**

Vérifiez avec le bon de livraison du client :
- Le client est toujours dans les **délais légaux de retour (30 jours** à compter de la réception)
- Il s'agit bien des **bons produits**
- Le produit **n'est pas endommagé**, sans trace d'usure (le produit ne doit pas avoir été porté)

**Le client doit ramener :**
- Le ou les bijou(x)
- L'emballage d'origine
- Le bon de livraison
- Le livret « Merci pour votre commande » complété du **numéro de retour**

**Étape 2 — Récupérer le numéro de retour**

Avant de déposer le produit en boutique, le client doit faire une **demande de retour sur le site internet**. Il obtient ainsi un numéro de retour.
- Récupérez ce numéro (le découper dans l'encart en bas de page du livret ou le noter sur le Bon de Livraison)
- **Apposez le tampon du magasin** dans l'encart « preuve de dépôt » — cela prouve au client que le magasin a bien récupéré le produit

**Étape 3 — Envoyer la marchandise en centrale**

Renvoyez le colis en centrale, accompagné du bon de livraison et du numéro de retour.

> Pour garder une trace : ajoutez une ligne sur le bon de colisage → **« retour client web : NOM client / numéro retour »**

**Étape 4 — Remboursement**

Une fois le colis reçu en centrale, nous effectuons un contrôle puis déclenchons le remboursement.

> ℹ️ Si l'article est défectueux et que le client souhaite le **faire réparer** plutôt que le retourner, voir la partie **2 — SAV** ci-dessous.

---

### 1.2 Le client souhaite échanger son article

Il s'agit d'un **échange traditionnel**, comme si le client avait acheté son article dans un autre magasin Aélys.

**Dans ODEIS :** Onglet **Ventes → Ventes et échanges**

1. Recherchez le nom du client → sélectionnez-le → code opérateur → cliquez sur la main pointée
2. Dans **« Magasin »**, sélectionnez **101 – Web** → **« Lancer la recherche »**
3. Vous verrez les achats du client sur le web → sélectionnez le produit à reprendre

**Concernant le produit ramené par le client :**

| Situation | Action |
|---|---|
| Produit Aélys PL ou marque que vous distribuez | Gardez le produit en magasin, demandez une nouvelle étiquette à la logistique |
| Produit d'une marque que vous ne distribuez pas | Effectuez un transfert à la centrale 398 en sélectionnant votre magasin comme origine |

---

## 2. SAV — Produit défectueux reçu suite à une commande web

Un client peut revenir en boutique si, lors de la réception de son bijou acheté sur le site, celui-ci est défectueux.

**Traitez les défectueux web comme un SAV classique.** Le magasin reprend le produit et si besoin l'envoie en réparation.

> ✅ **Important :** Dans l'intitulé du SAV, inscrivez **« SAV WEB »** pour assurer le suivi et distinguer les SAV web des SAV magasin classiques.
