# Commandes — Produits griffés, plaqué or, montres

## Procédure
1. Application commande spéciale → référence fournisseur → vérifier disponibilité.
2. Priorité : centrale → puis réseau (appel magasin).
3. Si produit absent de l'application : envoyer un mail à **stock Occitania** avec :
   - Code fournisseur
   - Référence fournisseur
   - Taille si applicable
   - Délai maximum souhaité

La centrale vérifie la dispo chez le fournisseur → commande EDI si possible.

## Règle remises
Produits remisés à taux = liquidation de stock → **aucune commande possible**.
