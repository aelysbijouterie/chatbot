# Commandes — Acier

Même procédure et mêmes règles que l'argent. Mêmes fournisseurs.

- Sans remise : Application commande spéciale → référence fournisseur. Priorité centrale, puis réseau.
- Avec remise (pastille %) : vérifier disponibilité centrale/réseau uniquement. Aucune commande fournisseur possible.
