# Commandes — Argent

## Argent sans remise
Même procédure que l'or : Application commande spéciale → référence fournisseur. Priorité centrale, puis réseau (appel magasin).

**Spécificités argent :**
- Tailles disponibles généralement entre 52 et 56.
- Tailles hors norme → mise à taille uniquement.
- Rétrécissement avec oxydes déconseillé.
- Tour complet, alliance, effet martelé/sablé → mise à taille impossible.
- Pas de fabrication sur mesure comme pour l'or.

Si aucun produit ne correspond → consulter le site Robbez Masson, rayon argent disponible.

## Argent avec remise (pastille %)
Vérifier uniquement la disponibilité en centrale ou sur le réseau. Aucune autre commande possible.
