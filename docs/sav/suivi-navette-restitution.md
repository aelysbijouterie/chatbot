# SAV — Suivi, navette et restitution

## Affectation atelier (navette hebdomadaire)
Avant toute affectation, vérifier pour chaque SAV :
- Un atelier destinataire renseigné
- Une photo prise
- Le poids renseigné
- Le travail demandé est clair
- Le produit est soigneusement emballé

**ODEIS → SAV → Affectation atelier → Saisie par atelier** → renseigner le numéro d'atelier (8003 ou 8116) → saisir un par un les numéros de fiche SAV → imprimer en deux exemplaires (un dans le colis, un conservé au magasin).

La navette part **le lundi et le jeudi** vers la centrale (398). Elle contient : SAV/devis, transferts inter-mag, mouvements de marchandises, une fois par mois les défectueux, et un **bon de colisage** récapitulatif.

## Suivi SAV
- Imprimer en deux exemplaires à la prise en charge
- Au bout de **3 semaines** : relance par mail à l'atelier (objet : nom du client + n° SAV)
- Une fois la réponse obtenue : noter les infos sur le papier SAV archivé
- **Contacter le client** pour le tenir informé (même sans retour atelier, l'appeler pour dire que le SAV est suivi)
- Noter toutes les informations sur la feuille (ex : "@atelier le 01/08, client contacté le 03/08")

## Restituer un SAV
1. Présenter le produit sur un **plateau**
2. Récapituler les actions menées (se baser sur la fiche atelier)
3. Donner des **conseils SAV** pour la suite
4. Sortir le SAV **informatiquement** (obligatoire, SAV payant ou non) : ODEIS → SAV → renseigner le numéro de SAV → valider → encaissement

## Retour SAV défectueux de l'atelier
Si la réparation présente un défaut :
1. **Retour atelier informatiquement** : ODEIS → SAV → Retour atelier
2. Créer un **nouveau SAV** en mentionnant le 1er numéro de SAV
3. Noter en **rouge** : **URGENT RETOUCHE**
4. Prévenir le client que le travail ne convient pas et que le produit est renvoyé
