# Correspondance référence web / référence magasin / référence fournisseur

CORRESPONDANCE REF SITE AELYS ET REF MAG COMMENT FAIRE ?
Comment savoir si un produit du site Aelys est en stock dans mon magasin ?
Odéis > interro > copier/coller la référence dans le champ ancienne référence
Si le produit est en stock dans votre magasin, vous verrez sa fiche stock apparaitre.
Si il n'y a pas de référence odéis qui s'affiche mais que vous souhaitez connaitre dans quel magasin est présent l'article :
Odéis > transferts > Interrogation des stocks > complète > dans le champ Réf. interne vous inscrivez la référence web puis vous validez.
Vous verrez ainsi où est présent le produit et vous connaitrez sa référence fournisseur.
