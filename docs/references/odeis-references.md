# Références et logiciel ODEIS

## Types de références produit
- **Référence fournisseur** : non unique, peut être identique sur deux produits. Utile pour communiquer avec les fournisseurs. Exemple : ME3188
- **Référence étiquette** : unique, pas de doublon possible. Commence par **398.XXXXXX**. Permet de suivre l'historique d'un produit.
- **Code style** : correspond à la vitrine dans laquelle le bijou doit être exposé.

## Code famille (premiers chiffres)
- **/1/** Montres
- **/2/** Bracelets de montres
- **/3/** Or 18k
- **/4/** Or 9k
- **/5/** Plaqué or
- **/6/** Argent
- **/7/** Acier
- **/8/** Fantaisie

## Fiche catalogue (ODEIS)
ODEIS → **Interro (loupe)** → saisir la référence étiquette → accès à la fiche catalogue (prix, fournisseur, code style, code famille, historique complet).
Cliquer sur **Histo** pour voir tout l'historique du produit.

## Moyens de règlement
- **Carte bleue** : acceptée. Les **cartes American Express ne sont pas acceptées**.
- **Espèces** : acceptées jusqu'à **1 000 €**, contrôler les billets avec la machine de contrôle.
- **Chèques** : acceptés selon les conditions du document "règlement min-max" dans Partage magasin.
- **Chèques cadeaux** : vérifier la validité dans Partage magasin > Formation nouvel entrant > semaine 1 > Chèques cadeaux.

## Paiement en plusieurs fois (PNF)
Disponible via la plateforme **ONEY** (3x ou 4x). Codes d'accès nécessaires. Document de référence dans Partage magasin > Formation nouvel entrant > semaine 3.

## Navette hebdomadaire
Chaque semaine, envoi le **lundi et le jeudi** vers la centrale 398, contenant :
- SAV/devis pris en charge
- Transferts inter-mag
- Mouvements de marchandises (équilibrages)
- Défectueux (une fois par mois)
- Bon de colisage récapitulatif
